# 记忆文件系统

本目录用于存储项目的核心知识和实现细节，便于快速查阅和复用。

## 目录结构

```
.memories/
├── README.md              # 记忆主目录说明
├── modules/               # 记忆模块目录
│   ├── INDEX.md           # 模块索引
│   └── <业务-主题>/       # 具体模块，如 user-auth
│       ├── README.md      # 模块导航
│       ├── PRD.md         # 产品需求、场景、边界
│       └── FUNCTION-*.md  # 功能实现文档
├── templates/             # 模块模板
└── scripts/               # 速查脚本
```

## 文件说明

| 文件 | 作用 |
|------|------|
| README.md | 模块导航，列出所有文档 |
| PRD.md | 产品需求：业务目标、用户场景、边界假设 |
| FUNCTION-*.md | 功能文档：输入输出、核心逻辑、关键代码、踩坑记录 |
| templates/ | 文档模板：新增功能或约束时优先复用 |

## 命名规范

- 模块目录：`业务-主题`，小写加连字符（如 `user-auth`）
- 功能文档：`FUNCTION-功能名.md`，大写加连字符（如 `FUNCTION-LOGIN.md`）

## 回写规则

每次代码发生这些变化时，必须同步更新对应模块文档：

- 新增业务能力
- 修改现有逻辑或接口
- 新增不变量、权限边界、风控限制
- 修改验证流程或测试要求
- 修正一次真实踩坑经验

建议优先使用 `templates/` 下的模板创建新文档，再补充具体实现细节。
